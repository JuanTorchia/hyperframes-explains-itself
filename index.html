Can HyperFrames explain HyperFrames?

What it is

HyperFrames turns web-native source files into video.

Developers can author scenes with HTML, CSS, JavaScript, and components.

Why it matters

HTML is inspectable. Video output becomes generated artifact.

<section

data-duration="10">

layout,

motion.
Git can diff
the actual
video source.

Setup target

Node 22 plus FFmpeg.

This repo validates the local environment before claiming any render result.

Step 1

Initialize the project.

$ npm install
$ npm run doctor

Step 2

Preview before rendering.

$ npm run dev
Scrub timing. Fix layout. Repeat.

Step 3

Render only after checks pass.

$ npm run check
$ npm run render

HTML is the source. MP4 is the artifact.
