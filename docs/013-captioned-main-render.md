# Captioned Main Render

## Purpose

This document records the first captioned variant of the main walkthrough. It is not a replacement for the original render yet. It is an experiment that proves curated captions can be mounted over the real video source and rendered through the same Docker path.

## Caption Source

The caption data is generated by:

```bash
npm run experiment:main-captions
```

The generated file is:

```text
compositions/captions-data.js
```

The captions are curated scene-level beats. They use `audio/generated/transcript.json` as timing evidence, but they do not use raw Whisper text directly. This keeps the final copy readable while preserving the build-log evidence for how timing was obtained.

## Variant Source

The variant template is:

```text
variants/main-with-captions/index.html
```

The runner temporarily swaps this template into `index.html`, runs HyperFrames commands, and restores the original `index.html` in a `finally` block:

```bash
npm run render:captions
```

This avoids replacing the canonical source while still using the normal root project render path.

## Result

The captioned render completed and the overlay is legible in sampled frames. The brand footer remains visible behind the caption area in some scenes; that is acceptable for the proof, but the final version should either move the footer or hide it while captions are active.

## Decision

Keep the original render as the baseline. Use the captioned render as article evidence and as the candidate direction for the final accessible version.
