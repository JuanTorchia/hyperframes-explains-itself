# Project Brief Prompt

Use this prompt to restate the project direction for an agent or collaborator.

```text
We are building a public tutorial repository called `hyperframes-explains-itself`.

Project thesis:
Use HyperFrames to explain HyperFrames.

Goal:
Create a real, reproducible, well-documented tutorial showing how to use HyperFrames by generating a video about HyperFrames with HyperFrames itself.

Constraints:
- Everything in the repository must be written in English.
- Tone should be technical, direct, human, and not corporate.
- Do not invent results.
- Do not claim anything has rendered until it has.
- Document commands only after validating them, or clearly mark them as pending.
- Keep a dated technical journal of decisions, mistakes, fixes, and results.

Initial output:
A roughly 60-second video called "HyperFrames in 60 Seconds".
```
